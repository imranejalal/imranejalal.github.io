TIPE · PREPARATORY CLASSES

Ambient Temperature Monitoring and Control Using Arduino & PID

For my TIPE, I developed an Arduino-based temperature monitoring and control system using a PID controller. It brought together programming, electronics, Tinkercad simulations, hands-on experimentation, and thermal modeling.

The project gave me a practical way to explore how software and hardware work together in an automated control system.

  • Arduino
  • C/C++
  • Python
  • Tinkercad
  • PID Control
