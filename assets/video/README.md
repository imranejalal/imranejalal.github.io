# Vidéo de pitch sur YouTube

La vidéo de présentation est hébergée sur YouTube :

**https://youtu.be/jkFv1a_8dXc**

Elle est intégrée dans **Career Development / Projet professionnel**, dans les
versions anglaise et française. Le lecteur permet la lecture et le plein écran,
sans démarrage automatique. Un lien direct vers YouTube figure sous la vidéo.
Le fichier MP4 n’est plus présent dans la version courante de ce dépôt.

## Remplacer la vidéo

1. Dans `index.html` et `fr/index.html`, rechercher `pitch-youtube`.
2. Remplacer l’identifiant `jkFv1a_8dXc` dans l’adresse du lecteur et mettre à jour
   le lien « Watch on YouTube » / « Voir la vidéo sur YouTube ».
3. Enregistrer sur `main` et attendre la publication GitHub Pages.

Le lecteur utilise `youtube-nocookie.com` et une politique de référent qui fournit
l’origine du portfolio à YouTube pour permettre la lecture intégrée.

## Interviews

Les trois interviews se trouvent sous la vidéo et les liens CV / LinkedIn,
dans `index.html` et `fr/index.html` : `interview-1`, `interview-2`, `interview-3`.
