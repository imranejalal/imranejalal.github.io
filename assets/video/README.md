# Déposer ma vidéo de pitch

Le site est déjà configuré pour lire automatiquement ce fichier :

**`assets/video/pitch.mp4`**

## Ajouter la vidéo sur GitHub

1. Renommer la vidéo **`pitch.mp4`** (tout en minuscules, sans espace).
2. Dans ce dossier `assets/video`, cliquer sur **Add file → Upload files**.
3. Glisser la vidéo, puis cliquer sur **Commit changes** pour l’enregistrer sur `main`.
4. Attendre la fin du déploiement GitHub Pages et actualiser le portfolio.

La vidéo apparaît dans **Career Development / Projet professionnel**, sur les
versions anglaise et française. Il n’y a aucun code à modifier.

Utiliser un vrai fichier MP4, idéalement encodé en H.264 pour la vidéo et AAC
pour le son. Changer seulement l’extension d’un autre format ne le convertit pas.

Tant que la vidéo n’est pas déposée, le site affiche « Vidéo à venir ».
Ce dépôt ne contient pas encore de vidéo de présentation.

## Remplacer la vidéo

Remplacer `pitch.mp4` par la nouvelle vidéo en conservant exactement le même
nom, puis enregistrer le changement dans le dépôt.

## Les trois interviews

Les trois emplacements sont sous la vidéo, dans `index.html` (anglais) et
`fr/index.html` (français). Rechercher `interview-1`, `interview-2`, `interview-3`.
Pour chaque personne, remplacer le titre par son vrai nom et le paragraphe par
son parcours, ses conseils et les enseignements de l’échange. Les textes actuels
sont explicitement des emplacements à compléter, sans profil inventé.
